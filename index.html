Batasan interpretasi inventaris

File inventaris berisi beberapa catatan untuk kombinasi cabang–produk yang sama dan tidak menyediakan tanggal pencatatan. Dashboard menghitung jumlah catatan, kombinasi unik, catatan berulang, serta distribusi nilai opname_stock. Nilai tersebut tidak dijumlahkan sebagai stok aktual dan tidak digunakan untuk menetapkan status stok kritis.

Filter tahun tidak diterapkan pada inventaris karena dataset tidak memiliki kolom tanggal. Filter provinsi, tipe cabang, dan kategori produk diterapkan melalui tabel referensi.
